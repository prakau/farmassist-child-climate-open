# Monitoring and evaluation

The system is designed to measure, but does not claim current values for:

| Indicator | Proposed definition |
|---|---|
| Valid observations | Accepted unique schema-valid records |
| Offline processing | Locally assessed records / assessed records |
| Sync success | Unique accepted-or-duplicate acknowledgements / approved attempts |
| Alert latency | Local assessment completion minus observation receipt |
| Active sites | Non-identifying sites reporting in a defined period |
| Completeness | Received expected sensor intervals / expected intervals |
| High-risk periods | Defined contiguous periods with high combined risk |
| Users trained | Aggregate adults completing defined training |
| Alert interpretation | Future test participants meeting a pre-set comprehension rubric |
| Connected uptime | Successful probes / scheduled probes while connection is expected |

Define denominators, time windows, missingness, targets, consent, and analysis before a pilot. Report uncertainty and failures; do not infer nutrition or child-health impact from environmental indicators.
