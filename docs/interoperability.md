# Interoperability

JSON and CSV use UTC ISO 8601 timestamps, UUID observation IDs, percentages on 0–100 scales, Celsius, controlled enums, and non-identifying site codes. The JSON Schema is the exchange contract and OpenAPI describes transport. Future adapters should version mappings, preserve provenance and units, reject identity fields, and use conformance fixtures. Sensor, OGC SensorThings, and local-language mappings are proposed future work, not implemented claims.
