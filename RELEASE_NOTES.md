# v0.1.0-alpha

FarmAssist Child Climate & Nutrition Intelligence is an early, open-source, offline-first reference prototype.

The release includes public prototype evidence: an authentic dashboard capture, FastAPI OpenAPI capture, and a 36-second offline assessment and synchronization demonstration. These assets use synthetic observations and prove software behavior only.

## Included

- Strict non-personal environmental observation schema
- Explainable configurable heat, water, and humidity-disease reference thresholds
- FastAPI, SQLite, OpenAPI, idempotent observation ingestion, site summaries, and aggregate-only public indicators
- Installable TypeScript PWA with network state, synthetic demonstration, reviewable local queue, and retry synchronization
- 360 deterministic synthetic records across three demo scenarios
- 15 automated tests, CI, dependency and secret scanning
- Safeguarding, privacy, governance, model/dataset cards, pilot protocol, monitoring framework, and 12-month roadmap

## Important limitations

This alpha requires independent agronomic, safeguarding, accessibility, security, and field validation. It is not a medical device or emergency warning system and makes no child-health, nutrition, yield, accuracy, UNICEF relationship, or field-impact claim. It is not production hardened.
