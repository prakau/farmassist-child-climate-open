# Twelve-month technical roadmap

All activities are proposed and subject to funding, approvals, partners, and evidence.

| Period | Planned work | Exit evidence |
|---|---|---|
| Months 1–2 | Architecture, safeguarding, licensing, schema, repository, baseline prototype | Reviewed public alpha and test report |
| Months 3–4 | Offline application, risk API, dashboard, local-language framework | Supervised usability protocol and working offline flow |
| Months 5–6 | IoT ingestion, synchronization, public indicators, documentation | Reproducible integration tests and privacy review |
| Months 7–9 | Pilot preparation, safeguarding approval, training materials, usability and data-quality testing | Required approvals before any field activity |
| Months 10–11 | Model improvements, accessibility, interoperability, independent-review preparation | Versioned validation package |
| Month 12 | Proposed stable release, evaluation report, implementation toolkit, scale plan | Evidence-qualified release decision |
