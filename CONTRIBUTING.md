# Contributing

Open an issue before substantial changes. Never submit personal, child, household, or precise-location data. Use synthetic site codes such as `DEMO-001`.

1. Fork and create a focused branch.
2. Run `make install && make test`.
3. Add tests and documentation for changed behavior.
4. Sign off that contributed data are synthetic and appropriately licensed.

Security and safeguarding reports must follow [SECURITY.md](SECURITY.md), not a public issue.
